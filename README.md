# Aditya Subramaniam — Portfolio (Apple-style version)

Plain HTML, CSS and JavaScript. No build step: open `index.html` in a browser to preview.

## Files
- `index.html` — page content
- `styles.css` — all styling (colour and type tokens at the top)
- `script.js` — footer year, light/dark toggle, scroll reveal
- `resume.pdf` — add your resume here (the Resume buttons link to it)

## Hosting on GitHub Pages
1. Create a repo (e.g. `portfolio`, or `YOUR-USERNAME.github.io` for a root URL).
2. Add these files to it and push.
3. Repo Settings → Pages → Source: deploy from the `main` branch, root folder.

Netlify or Vercel also work: import the repo and leave the build command empty.
